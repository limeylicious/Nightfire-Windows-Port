# Credits and rights

- **Original game:** *007 Nightfire* and its executable, characters, artwork, music, films, levels, dialogue and other content remain the property of their respective rights holders. No original game files are included here. This is an independent compatibility and preservation project, not an official release.
- **Nightfire-specific port work:** AI agents, including OpenAI Codex and Anthropic Claude, carried out implementation, static-recompilation repair, debugging, tests and documentation under the owner's direction. Claude also contributed independent technical reviews and planning. The owner provided the original game privately and performed gameplay testing and reporting. “AI-developed” describes this project's new port work; it does **not** describe or claim authorship of the original game or upstream projects.

The pinned checkout used in this project is `051a128df5ec27ef14f1ceaaead11c5457321eef`. Most toolkit code is MIT licensed; preserve its [LICENSE](https://github.com/sp00nznet/xboxrecomp/blob/main/LICENSE), [NOTICE](https://github.com/sp00nznet/xboxrecomp/blob/main/NOTICE) and component notices when using or redistributing it.
- **[xemu](https://github.com/xemu-project/xemu) contributors:** selected APU and NV2A code in `xboxrecomp` is LGPL-2.1-or-later, with individual copyright notices and terms listed in the toolkit's NOTICE and LICENSES directory. The toolkit is a separate dependency and is not vendored here.
- **[NightfireResearch/nightfire-re](https://github.com/NightfireResearch/nightfire-re) and [nightfire-cxbx](https://github.com/NightfireResearch/nightfire-cxbx):** research and function-label references. Their labels are treated as leads and checked against this project's PAL executable; their implementation code has not been imported into this source snapshot.
- **Other hardware and engine references:** xemu, Cxbx-Reloaded, XboxDev/nxdk and xboxdevwiki have informed investigation of Xbox behavior. Reference use does not imply that their code is included here. See the original project notes for per-file provenance where relevant.
- **Analysis tools:** [Ghidra](https://github.com/NationalSecurityAgency/ghidra) and [XboxDev/ghidra-xbe](https://github.com/XboxDev/ghidra-xbe) supported local PAL executable analysis. Microsoft compiler/debugging tools and Windows/D3D11 diagnostics supported builds and validation. These tools and their binary outputs are not bundled in this snapshot.

The separate Driving-510 source snapshot preserves existing source notices. It includes project-specific bridge additions and files derived from the previously credited runtime foundation; it is not a claim that every line was originally authored by an AI agent. Handwritten D3D/HLSL adapter code is distinct from extracted Xbox shader/program tables, which remain excluded under the export policy.

This repository does not place the original game, generated translations, the toolkit or any third-party material under a new licence. The Nightfire-specific files have no repository-wide open-source licence grant at this stage. Component copyright and licence notices in source files remain effective.
