# Nightfire PC alpha 0.1

The first public alpha of the native Windows port of the PAL Xbox edition of *007 Nightfire*.

**No game files are included.** Download "Source code (zip)" below. Its Setup builds both engines on your PC from your own PAL disc.

## What you need

- Windows 10 or 11 (64-bit) and a DirectX 11 graphics card.
- Your own PAL *007 Nightfire* disc, extracted, so that you have `default.xbe` and `Driving.xbe`. Setup checks both against the PAL release.
- [Python](https://www.python.org/downloads/) 3.8 or newer, [Git for Windows](https://git-scm.com/download/win) and [Build Tools for Visual Studio 2022](https://visualstudio.microsoft.com/downloads/) with the "Desktop development with C++" workload.
- About 2 GB of free space. Windows N editions also need the Media Feature Pack for the movies.

## Install

1. Unpack "Source code (zip)".
2. Copy the contents of your extracted disc into `release\alpha\Game Files`.
3. Double-click `release\alpha\Setup.cmd`. The first run takes about 15 minutes on a recent laptop: it downloads the translator, translates the game's code, applies the port's fixes and compiles both engines.
4. Play with `release\alpha\Play Nightfire.cmd`.

`release\alpha\README.txt` covers the other launchers, the controls, the PC settings and what to send if something goes wrong. The engines Setup builds are made from the game's own code, so don't share the folder once Setup has run.

## What's in it

- Both engines, the missions and the car levels, run as native Windows code without emulating the Xbox graphics or sound chips.
- Action and Driving hand over in one window, as on the console.
- Split-screen for up to four players on one PC, with controllers or one shared keyboard and mouse.
- Optional PC settings (F10, or Options > Audio/Video > PC Options): internal resolution up to 4x, widescreen, windowed or fullscreen, key binds and frame rate options.
- Every launcher writes a crash or freeze report to a per-session folder.

## Known issues

- Only Paris Prelude has been played in the car engine. The other car levels are untested.
- Smooth Motion (in-between pictures for high-refresh screens) is experimental.
- Online play is not in the alpha's menus yet.
- On-screen button prompts show Xbox buttons, even with the keyboard.
- Split-screen has not been played with the missions' new sound yet.
- Sound plays without the console's reverb and other effects.
- The game runs slower on battery power.

The full list is in `release\alpha\README.txt`.
