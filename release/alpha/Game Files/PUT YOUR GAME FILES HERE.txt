Put the contents of your extracted PAL 007 Nightfire disc in this folder, so that
default.xbe and Driving.xbe sit directly inside it (next to this note), then run Setup.cmd.

The files stay here: Setup reads them to build the engines and links the engines to this
folder. Git ignores everything in this folder except this note.

On the owner's workshop laptop you can leave this folder empty: Setup links it to the
workshop's nightfire-port\game_files instead.
